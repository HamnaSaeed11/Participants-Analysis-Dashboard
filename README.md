# Participants Analysis Dashboard

## Project Overview

The **Participants Analysis Dashboard** is an interactive data visualization project designed to analyze participant demographics, enrollment trends, and study-hour patterns across different years.

The dashboard provides meaningful insights into participant distribution by age group, gender, school, country, county, and municipality. It enables users to explore demographic patterns and understand changes in participation over time through interactive filters and visualizations.

## Dashboard Preview

![Participants Analysis Dashboard](images/participants-analysis-dashboard.png)

## Key Features

- **Participant Demographics:** Analyze participants across different age brackets.
- **Gender Analysis:** Compare male and female participant distributions.
- **Yearly Trends:** Track participant growth and changes over time.
- **School Analysis:** Explore participant distribution across educational institutions.
- **Geographical Analysis:** Examine participation by country, county, and municipality.
- **Study Hours Analysis:** Monitor yearly study-hour trends.
- **Interactive Filters:** Filter data by year, participant type, school, county, municipality, and age.
